# 1.1.3：文件夹导入、批量规模与控件布局

## 基线

先从 Gitea 快进同步 main 到 `2a5cdb8244eaca1b03cbcf65a38395e824e4df26`（AVIF 完整质量范围修复），再做本次修改。没有修改转码算法。

## 导入

- 首页和非空处理列表增加「文件夹导入」，使用系统 OpenDocumentTree；默认包含子文件夹，也可以只读取当前目录。支持 JPEG、HEIC/HEIF、AVIF、JXL；跳过视频、虚拟文档和不支持的扩展名。
- 相册导入原先直接 `take(1000)`；这是应用导入层的截断，不是编码器容量限制。现在相册和文件夹通过 Flow 逐项读取，每 32 张提交队列，每组最多 4 个检测任务，不再一次创建与图片总数相同的协程。HDR 筛选同样限制在 4 个任务一组。
- 遍历目录使用迭代栈和已访问集合，避免递归调用栈、循环目录及同一 URI 重复入队。不可读子目录汇总提示；根目录读取失败明确报错。
- 持久树权限由整个目录共享，子文档不逐个申请持久权限。不支持持久权限的提供方仍复制为应用私有输入，复制循环检查取消状态。
- 可取消导入，已提交和已准备完成的照片保留；已提交的检测批次继续完成。导入及扫描期间禁止启动转换，也禁止同时启动另一项导入。
- 单张文件复制大小、解码像素数等既有保护保留。队列元数据仍与条目数成正比，不承诺无限内存或所有第三方云盘性能。
- 输出仍沿用当前格式、相册自动保存设置；不按来源子目录重建输出目录。忽略 Live 的设置同时适用于目录导入。
- 系统目录访问的边界按 [Android SAF 官方文档](https://developer.android.com/training/data-storage/shared/documents-files)；部分受保护目录无法通过系统选择器授权。

## UI

- 参数页的说明与默认参数操作分行；操作按钮按可用宽度换行。大字体下优先移除装饰图标，保留完整文字。
- 输出方案徽标允许换行，进阶参数标题为展开箭头预留宽度。
- 追加照片、相册及文件夹导入移至队列标题下；底部只保留开始／停止按钮。取消原先紧贴导航的圆角底座，与页面导航留出 12 dp 间距；运行时隐藏导入入口，停止按钮使用较轻的 tonal 配色。
- 折叠屏维持左侧队列、右侧参数和操作布局。

## 验证

- API 35 arm64 模拟器，独立 `.uiqa` 包：40 项测试通过。包含 Adaptive、滑动、撤销、历史、自动替换、Live 过滤、持久队列、实际导航与操作区、目录导入。
- 真实 MediaStore 测试相册 1001 张完整入队；测试 DocumentsProvider 的多层目录 1003 张完整入队，全部原生 probe 成功。覆盖非递归、循环目录、重复引用、不可读子目录、重复导入和中途取消。
- 测试提供方使用单独测试 APK 进程，由该 UID 授予真实可持久树权限；验证子图均保留文档 URI，且只新增 1 个持久目录权限。测试 Provider/授权 Activity 不进入应用 APK。
- 默认参数操作检查 280/320/400/640 dp × 1/1.3/2 倍字体，共 12 种组合，完整文字单行、不截断、两个回调有效。实际主页检查 320 dp 大字体、400 dp 手机及 840 dp 双栏。
- JVM 24 项通过、1 项既有跳过；截图回归 5/5。Fold 参考图更新前已检查差异：仅进阶参数标题预留箭头后正常换行。
- Debug/Release 构建、两种 Lint、仓库检查、git diff whitespace 检查通过。
- APK v2 debug 签名验证通过；ZIP 16 KB 对齐通过；全部 3 个原生库 LOAD 对齐至少 16384。
- 未安装到用户实体手机，未验证各厂商文件管理器或云盘的实机选择流程，也未重新跑原生转码质量审计。
