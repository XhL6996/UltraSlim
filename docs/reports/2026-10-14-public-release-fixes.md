# 1.1.10：公开发行审查后的修复

针对 [首次公开发行审查](2026-10-14-public-release-review.md) 落地修复，版本更新为 **1.1.10 / 22**。保留审查前已有工作区改动；本轮没有提交、推送、发布或覆盖个人手机。

## 保存恢复与成品保护

`MediaStoreSaver` 不再仅凭名称认领已保存文件。恢复时检查可读字节数和 SHA-256；同名异内容、已改写或 pending 的项保留，正确成品使用不冲突的编号名称另存。编号副本也能在进程中断后重新识别。查询中的 `%`、`_` 和反斜杠按字面转义。

新写入的相册副本在发布前后校验；`OutputStore` 在更新历史并删除私有副本之前再次核对内容。失败时保留应用内成品供重试。内容相同只代表保存字节一致，原有 SDR/HDR 平台解码检查仍然保留。

新增仪器回归覆盖：已发布成品被改写、历史 checkpoint 尚未完成时重试，不得误认另一文件；正确副本另存后再次中断能恢复编号副本，不重复发布。现有缺文件保存失败、重试和幂等测试继续通过。

## 奇数尺寸 SDR AVIF

对照实验比较 AOM / SVT、4:4:4 / 4:2:0 和分块容器。Android 16 模拟器拒绝原来的奇数 SDR 4:4:4 分块图；4:2:0 偶数编码画布加 clean aperture 在 Android 15/16 均可解码。

纯 SDR 改回 SVT 4:2:0，包括大于 4096 的奇数尺寸。分块编码仅补齐画布，容器的可见尺寸保持原图大小，不裁掉源像素、不缩放、不跳过平台校验。**HDR 奇数尺寸的 AOM 4:4:4 分支保持不变**，不将 SDR 的结论套用于 gain map。

平台回归对 513×385、5001×513、513×5001、5002×513、5002×514 分别执行保存前采样解码及全尺寸 ImageDecoder 解码，并断言原尺寸与无 gain map。两个模拟器系统均通过。主机回归另检查 4:2:0 合法偶数编码尺寸、原始可见尺寸及实际解码尺寸。AGENTS 和兼容文档已更正旧结论；不据此保证全部厂商相册均已验收。

## 测试入口与发行准备

- 删除协调回归接受标准 `.verifyqa`，仍拒绝日常使用包；保留原 `.optqa` 验证入口。
- 队列动画测试等待 Flow 采样后的实际置顶键序，再检查动画帧，避免把 Compose 手动时钟当作真实采样时钟。
- 构建时生成 `assets/open-source-notices.txt`，包含项目 GPL、现有原生许可快照、Release 运行时依赖清单及 AAR/JAR 内的 LICENSE/NOTICE；设置中新增离线阅读入口。许可材料不等于完整源码归档或自动合规审查。
- 新增外部密钥签名配置及 `scripts/build_release.sh`。环境变量缺失/不完整时明确报错；脚本关闭配置缓存，校验对齐和证书，拒绝 Android Debug 证书，并为正式签名包输出校验和及声明附件。未生成长期发行密钥。
- README / COMPATIBILITY 明确自动替换须在首页逐批主动确认，以及 Android 8/9 仅转换/分享导出、Android 10+ 才支持直接入册。
